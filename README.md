# Criminal Detection System

## Overview

This project is developed using Python and OpenCV for criminal detection through image processing. MySQL is used to store and manage criminal records.

## Technologies Used

* Python
* OpenCV
* NumPy
* MySQL

## Features

* Face detection using OpenCV
* Criminal record management
* Real-time detection
* Admin functionality

## How to Run

1. Clone the repository
2. Install required packages:

```bash id="b6l2wp"
pip install -r requirements.txt
```

3. Run the project:

```bash id="xt9p1s"
python main.py
```
